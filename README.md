# IEEE 39모선 데이터센터 입지 · 가산점 A

압축을 풀고 MATLAB의 현재 폴더를 `run_bonusA.m`이 있는 폴더로 설정하세요. 동봉한 입력은 수업에서 제공한 원본 엑셀입니다. 시간 1은 1월 1일 00시, 8760은 12월 31일 23시입니다.

## 실행

```matlab
[ranking,site] = run_bonusA("preview"); % 솔버 없이 연간 후보 비교
r = show_bonusA(25,5684);               % 모선, 시간 번호를 바꿔 계통도·표 표시
r = show_bonusA(25,15);                 % 첫날 계통도와 시간별 ON/OFF 그림
run_bonusA("demo",120);                 % 25번, 첫 48시간을 처음부터 독립적으로 최적화
[ranking,site] = run_bonusA("solve",300); % 후보당 300초의 연간 MILP
```

- `run_bonusA`의 기본 동작은 `solve`입니다. 결과를 즉시 읽을 때는 `preview`를 사용하세요. `show_bonusA`의 두 번째 그림에는 선택일의 24시간이 표시됩니다. 선로 이용률은 절댓값 기준이고 음의 조류는 역방향을 뜻합니다.
- 계산에는 MATLAB Optimization Toolbox의 `intlinprog`를 우선 사용합니다. 도구상자가 없으면 MATLAB R2021b 이상의 `pyrunfile`과 MATLAB 버전에서 지원하는 Python, NumPy, SciPy 1.9 이상을 사용할 수 있습니다. MATLAB에서 `pyenv`로 사용할 Python을 확인하고 그 환경에 `python -m pip install numpy scipy`로 설치하세요. 백엔드를 지정하려면 `run_bonusA("demo",120,"scipy")` 또는 `"matlab"`을 사용하세요. 두 백엔드에 같은 목적함수와 희소 제약행렬을 전달합니다. 기본형의 linprog는 호출하지 않습니다.
- 연간 모형은 후보 하나당 87,600개 이진변수가 있어 PC 메모리와 계산 시간이 많이 필요합니다. 제한시간은 후보별 솔버 탐색시간입니다. 모형 작성·파일 전송·솔버 초기화는 추가 시간이 필요할 수 있습니다.
- 연간 모형이 무거우면 `run_bonusA("bounds",20)`으로 경쟁 후보를 168시간씩 나누어 비용 하한을 강화할 수 있습니다. 20초는 블록 하나당 제한입니다. 마지막 블록은 남은 시간만 사용합니다. 블록 경계에서 발전 상태와 출력 연결을 풀어 얻은 비용 하한을 합산합니다. 블록의 운전 결정을 연간 운전표로 이어 붙이지 않습니다.
- 결과는 `results/ranking.csv`와 후보별 MAT 파일에 저장됩니다. 다음 실행에서는 저장된 후보별 운전표와 하한을 재사용합니다. 같은 폴더에서는 한 번에 한 세션에서 실행하세요. 더 긴 탐색을 하려면 제한시간을 늘려 재실행하세요. 솔버 탐색 트리 자체는 다시 시작합니다.

## 연간 입지 판단

1. 기본형에서 이미 운전 불가능한 시간이 있는 22곳은 UC 제약을 추가해도 공급이 불가능합니다. 같은 입력에서 기본형의 제약을 모두 만족한 2, 9, 25, 26, 27, 28, 29번을 연간 비교합니다. 엑셀을 바꾸면 이 선별 결과와 동봉 운전표가 무효가 되므로 코드가 원본 일치 여부를 검사합니다.
2. 연간 유효한 운전표의 비용은 해당 입지의 **상한**입니다. 기본형 연간 비용은 **하한**입니다. 추가 비용은 음수가 될 수 없고 UC 제약을 추가하면 선택 가능한 운전 조합이 줄기 때문입니다. 연간 MILP에서는 솔버의 최선 하한을, 블록 모드에서는 완화된 블록들의 하한 합을 반영합니다.
3. 현재 최소 상한이 다른 모든 후보 하한보다 낮을 때만 `site.CertifiedSite=true`를 표시합니다. 수치 여유를 위해 달러 단위의 보수적 여백을 둡니다. 이 조건은 **입지**를 증명합니다. 해당 모선의 정확한 최소 연간 운영비는 그 모선 자체의 상한·하한 차이까지 확인해야 합니다. 동률이거나 구간이 겹치면 미확정으로 남깁니다.
4. 배포 시점의 연간 비용은 `data/verified_annual.csv`에서 볼 수 있습니다. 25번은 583,373,625.22달러입니다. 첫 48시간을 시간별 HiGHS MILP로 다시 풀고 기존 운전표의 나머지 시간에 연결해 검증했습니다. 나머지 후보의 초기 운전표는 이전 일 단위 기동·정지 버전의 연간 실행 가능 해입니다. 이 값들은 연간 UC의 검증된 초기 상한입니다.

## 교수님께 설명할 코드

| 파일 | 확인할 내용 |
|---|---|
| uc_inputs.m | 원본의 발전기·선로·재생에너지·연간 수요·기동정지 시트를 읽고 PTDF를 만듭니다. |
| uc_model.m | 시간별 수급균형, 선로 양방향 정격, 발전기 상태전이, 출력범위, 최소 운전시간/정지시간과 램프 제약을 만듭니다. |
| uc_solve.m | intlinprog 또는 SciPy HiGHS를 호출하고 연간 실행 가능 비용과 비교할 솔버 하한을 받습니다. |
| uc_audit.m | 최적화 행렬과 별도로 모선별 전력수지, 선로, 출력, 상태 지속시간, 램프 및 비용을 재계산합니다. |
| run_bonusA.m | 후보 선별, 상한/하한, 입지 판정, 연간 결과 저장을 담당합니다. |
| show_bonusA.m | 그림, 선로 혼잡 시간, 발전기별 기동·정지 횟수와 발전량, 재생에너지 이용·출력제한 표를 표시합니다. |

한 시간의 목적함수는 일반발전기별 **변동비 × 출력 × 1시간 + 무부하비 × 가동 상태 × 1시간 + 기동비 × 기동 여부**의 합입니다. 이 값을 모든 시간에 걸쳐 최소화합니다. 엑셀에 정지비는 없으므로 별도 정지 비용은 0입니다.

- U는 가동 상태(0 또는 1), Y는 기동, Z는 정지입니다. U(t)−U(t−1)=Y(t)−Z(t)이고 Pmin·U ≤ P ≤ Pmax·U입니다. 최근 최소운전시간 안에 기동했으면 현재 U=1, 최근 최소정지시간 안에 정지했으면 현재 U=0이어야 합니다. 이 제약들이 Y와 Z의 동시 발생도 막으므로 U만 이진으로 두어도 Y와 Z가 0/1로 결정됩니다.
- 1시간마다 일반발전과 실제 재생에너지 출력의 합이 기존 부하와 데이터센터 부하의 합과 일치합니다. 재생에너지 출력은 0부터 가용출력까지 허용하며, 차이가 출력제한입니다. 수요차단 변수는 없습니다. 선로 조류는 PTDF로 계산하고 양방향 정격을 적용합니다. 손실을 생략하는 DC-OPF를 사용합니다.
- 초기상태의 부호는 직전 ON/OFF, 절댓값은 그 상태를 유지한 시간입니다. 남은 최소 운전·정지시간을 첫 시간부터 적용합니다. 초기 MW가 없어서 기존 ON 발전기는 첫 시간에만 직전 출력과의 램프 검사를 생략합니다. 초기 OFF는 0 MW에서 출발합니다.
- 정상 운전 중에는 엑셀의 시간당 증감발률을 적용합니다. 별도 기동·정지 램프가 없으므로 상태 전환 때는 max(최소출력, 증감발률)까지 허용합니다. 이 가정으로 최소출력이 정상 램프보다 큰 발전기도 1시간에 최소출력으로 기동할 수 있습니다. 연말까지는 최소시간을 지키되 다음 해의 미제공 수요·비용·종료상태는 강제하지 않습니다.

## 48시간 실습 검증

`data/demo25_48h.csv`에는 독립 구현으로 계산한 25번 모선 연초 48시간의 출력과 상태가 있습니다. 총비용과 HiGHS의 비용 하한은 모두 약 2,853,674.40달러였습니다. 재계산한 해는 여러 최적해 중 다른 운전표일 수 있으므로 총비용과 제약 위반으로 비교하세요. 일반발전기 G10은 최소출력·기동비·무부하비가 모두 0이라 출력 0일 때 상태가 달라질 수 있습니다. 48시간 결과는 연간 최적성을 입증하지 않습니다.
